# Changelog

## 0.1.0

Initial OMNIA MCP release.

- Four stdio tools for typed evaluation, bounded batches, capabilities, and decision retrieval.
- Shared OMNIA decision policy and a local SQLite ledger.
- JEV through TypeSafe and optional local LAYA 0.3.20.
- Command-line diagnostics, schema export, and version reporting.
- Client recipes, source installation, Docker build, and CI.
- Provider-specific rounded-output validation with normalization and answer-consistency checks.
- A multilingual acceptance runner with recorded real JEV and local LAYA evidence.

Provider accuracy, performance, and individual client compatibility require separate recorded validation. No PyPI or container-registry publication is implied.
